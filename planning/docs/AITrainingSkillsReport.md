## ⚠️ Ghi Chú: Không Có Skill Dạy Thuật Toán (DSA)

> Repo này **không có skill chuyên biệt về Algorithms / Data Structures** (Big-O, sorting, graph traversal, dynamic programming, v.v.). Focus của repo là engineering workflow và coding standards — không phải CS fundamentals.

**Workaround — 2 cách thay thế:**

| Cách                                | Skill             | Dùng Như Thế Nào                                                                                                  |
| ----------------------------------- | ----------------- | ----------------------------------------------------------------------------------------------------------------- |
| Phân tích algorithm trong code thực | `logic-lens`      | Yêu cầu AI review algorithm correctness, boundary conditions, time/space complexity của code bạn đang viết        |
| Học DSA theo kiểu senior            | `uncle-bob-craft` | Hỏi AI giải thích trade-offs: "why this data structure?", "what's the complexity?", "when would you switch to X?" |

**Ví dụ prompt kết hợp:**

```
Dùng uncle-bob-craft + logic-lens để review hàm này:
- Complexity là O(n²) có chấp nhận được không?
- Có data structure nào tốt hơn không?
- Algorithm có edge case nào bị miss không?
```
