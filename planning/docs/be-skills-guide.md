# 🚀 Professional Backend Engineering & Ecommerce API Guide

Chào mừng bạn đến với lộ trình phát triển kỹ năng Backend chuyên nghiệp. Tài liệu này được thiết kế để cung cấp cho bạn những kỹ năng cần thiết nhất từ mức độ thực thi cơ bản đến kiến trúc sư hệ thống (Senior/Architect).

---

## 🟢 1. Nền tảng & Framework

Làm chủ ngôn ngữ và framework cốt lõi để xây dựng ứng dụng an toàn và hiệu năng.

- \***\*nestjs-expert\*\***: Chuyên gia NestJS. Làm chủ Module, Dependency Injection, Testing và các giải pháp backend phức tạp.
- \***\*typescript-advanced-types\*\***: Sử dụng các kiểu dữ liệu nâng cao (Generics, Mapped Types, Utility Types) để đảm bảo type-safety cho logic Ecommerce.
- \***\*zod-validation-expert\*\***: Xây dựng hệ thống validation dữ liệu đầu vào (DTO) cực mạnh và tự động hóa schema validation.
- \***\*javascript-mastery\*\***: Hiểu sâu về Event Loop, Async/Await và tối ưu hóa xử lý bất đồng bộ trong Node.js.

## 🚀 2. Thiết kế & Phát triển API (REST/GraphQL)

Kỹ năng viết API chuẩn công nghiệp, dễ sử dụng và có khả năng mở rộng tốt.

- \***\*api-endpoint-builder\*\***: Kỹ năng "thực chiến" viết API Endpoint chuyên nghiệp từ Route, Validation đến Error Handling.
- \***\*api-design-principles\*\***: Các nguyên tắc thiết kế API REST & GraphQL trực quan, bền vững và tuân thủ chuẩn cộng đồng.
- \***\*api-patterns\*\***: Áp dụng các pattern nâng cao: HATEOAS, Versioning, Cursor-based Pagination và API Gateway.
- \***\*graphql-architect\*\***: Thiết kế Schema, Resolver và Federation cho các hệ thống lớn đòi hỏi linh hoạt dữ liệu.
- \***\*error-handling-patterns\*\***: Xây dựng hệ thống xử lý lỗi nhất quán, chuyên nghiệp giúp API tin cậy và dễ debug.

## 🏗️ 3. Kiến trúc & Mở rộng (Senior Level)

Tầm nhìn của một kiến trúc sư - thiết kế hệ thống có thể chịu tải và bảo trì dễ dàng.

- \***\*senior-architect\*\***: Tư duy hệ thống, quản lý technical debt và dẫn dắt các quyết định công nghệ quan trọng.
- \***\*architecture-patterns\*\***: Làm chủ các architecture patterns: Event-driven, Microservices, Hexagonal, Clean Architecture.
- \***\*architecture-decision-records\*\***: Kỹ năng ghi chép và quản lý ADRs để theo dõi lịch sử và lý do của các quyết định kiến trúc.
- \***\*backend-architect\*\***: Thiết kế service boundaries, định nghĩa giao tiếp giữa các services và mở rộng quy mô.
- \***\*cqrs-implementation\*\***: Tách biệt mô hình Đọc và Ghi để tối ưu hiệu năng và khả năng mở rộng cho hệ thống lớn.

## 💾 4. Quản trị Dữ liệu (Deep Review)

Dữ liệu là trái tim của Ecommerce. Làm chủ DB là bắt buộc để hệ thống vận hành trơn tru.

- \***\*prisma-expert\*\***: Chuyên gia sử dụng Prisma ORM. Giải quyết triệt để N+1, migration an toàn và tối ưu hóa quan hệ phức tạp.
- \***\*sql-pro\*\***: Master SQL nâng cao: CTEs, Window functions, tối ưu hóa Query Plans và thiết kế Schema chuẩn hóa.
- \***\*postgresql-optimization\*\***: Quy trình tối ưu hóa hiệu năng Database toàn diện cho các hệ thống eCommerce chịu tải cao.
- \***\*sql-optimization-patterns\*\***: Các mẫu tối ưu hóa SQL, chiến lược đánh Index và phân tích Query Plan chuyên sâu.
- \***\*database-design\*\***: Thiết kế mô hình dữ liệu Ecommerce (Product, Order, Inventory) linh hoạt và tối ưu Index.
- \***\*algolia-search\*\***: Tích hợp công cụ tìm kiếm mạnh mẽ, giúp khách hàng tìm thấy sản phẩm nhanh nhất.

## 🔑 5. Auth, Roles & Security

Bảo vệ tài khoản khách hàng và dữ liệu doanh nghiệp là ưu tiên hàng đầu.

- \***\*auth-implementation-patterns\*\***: Làm chủ hệ thống Roles (RBAC), JWT, Secure Sessions và các flow đăng nhập bảo mật cao.
- \***\*api-security-best-practices\*\***: Ngăn chặn OWASP Top 10, chống SQL Injection, XSS và áp dụng Rate Limiting bảo vệ API.
- \***\*web-security-testing\*\***: Quy trình thử nghiệm và kiểm soát an ninh (Pentesting) cho ứng dụng server-side.

## 💳 6. Ecommerce & Hệ thống Features

Các tính năng đặc thù giúp xây dựng nên một nền tảng bán hàng hoàn chỉnh.

- \***\*payment-integration\*\***: Tích hợp cổng thanh toán chuyên nghiệp, xử lý Webhooks và đảm bảo tính Idempotency khi giao dịch.
- \***\*stripe-integration\*\***: Chuyên sâu về hệ sinh thái Stripe: Checkout, Subscriptions và API Billing.
- \***\*file-uploads\*\***: Quản lý hình ảnh/video sản phẩm hiệu quả thông qua S3, Cloudflare R2 và tối ưu hóa dung lượng ảnh.
- \***\*inventory-demand-planning\*\***: Logic quản lý kho hàng, dự báo tồn kho và xử lý đơn hàng phức tạp.

## 🧪 7. Chất lượng Code & Quy trình (Refactor & Review)

Viết code sạch và làm việc nhóm hiệu quả là dấu ấn của một Senior Backend.

- \***\*code-refactoring-refactor-clean\*\***: Kỹ năng Refactor chuyên sâu: Biến code rối thành code sạch, xử lý code smell và tech debt.
- \***\*code-review-ai-ai-review\*\***: Tận dụng sức mạnh AI để tự động hóa việc soát lỗi, đề xuất tối ưu hóa logic và đảm bảo chuẩn quy trình.
- \***\*code-review-excellence\*\***: Quy trình Code Review chuẩn mực giúp nâng cao chất lượng code của toàn team.
- \***\*test-driven-development\*\***: Quy trình Red-Green-Refactor giúp viết code chính xác, giảm thiểu bug và tự tin khi refactor.
- \***\*javascript-testing-patterns\*\***: Chiến lược kiểm thử toàn diện: Unit Test, Integration Test và E2E Test cho Backend.

## ⚙️ 8. Git & Workflow

Quản lý mã nguồn chuyên nghiệp, giảm thiểu conflict và tự động hóa.

- \***\*commit\*\***: Làm chủ chuẩn Conventional Commits giúp lịch sử Git sạch, dễ tra cứu và tự động hóa versioning.
- \***\*git-advanced-workflows\*\***: Kỹ năng nâng cao: Rebase, Cherry-pick, xử lý Conflict phức tạp và Branching Strategy.
- \***\*git-hooks-automation\*\***: Tự động hóa kiểm tra code trước khi commit bằng Husky và Git hooks.

## 📐 9. Tiêu chuẩn & Mẫu (Patterns & Scaffolding)

Xây dựng nền móng dự án vững chắc, tiết kiệm thời gian khởi tạo.

- \***\*cc-skill-backend-patterns\*\***: Tập hợp các mẫu thiết kế: Repository Pattern, Service Layer, Middleware và Error Handling chuẩn.
- \***\*cc-skill-coding-standards\*\***: Bộ tiêu chuẩn về đặt tên, cấu trúc thư mục (Folder Structure) và viết Clean Code.
- \***\*nx-workspace-patterns\*\***: Làm chủ Monorepo và Scaffolding chuyên nghiệp cho các hệ thống backend quy mô lớn.

## 🚀 10. Vận hành & Triển khai

Đưa code của bạn ra thế giới thực một cách an toàn và tự động.

- \***\*deployment-pipeline-design\*\***: Thiết kế các luồng CI/CD (GitHub Actions) để tự động hóa build/test/deploy.
- \***\*docker-expert\*\***: Container hóa ứng dụng, tối ưu hóa Dockerfile và quản lý các services môi trường local/staging.
- \***\*kubernetes-architect\*\***: Triển khai và vận hành hệ thống trên K8s, quản lý Auto-scaling và Resilience.
- \***\*k6-load-testing\*\***: Viết script và thực hiện kiểm thử tải (Load/Stress Testing) để đảm bảo hệ thống chịu tải tốt.
- \***\*observability-engineer\*\***: Xây dựng hệ thống giám sát (Monitoring), quản lý Log tập trung và truy vết lỗi (Tracing).
- \***\*sentry-automation\*\***: Tự động hóa việc theo dõi lỗi, cảnh báo và triệt tiêu các vấn đề phát sinh trong production.

## 🛠️ 11. Meta-Skills & Công cụ

Kỹ năng giúp bạn làm việc thông minh hơn và mở rộng khả năng của công cụ AI.

- \***\*skill-creator\*\***: Tự động hóa quy trình tạo các kỹ năng mới cho AI, biến AI thành trợ lý chuyên dụng của riêng bạn.
- \***\*build\*\***: Quy trình 4 bước chuẩn để xây dựng tính năng: Nghiên cứu -> Lên kế hoạch -> Theo dõi -> Thực thi.
- \***\*mcp-builder\*\***: Xây dựng các Model Context Protocol server tùy chỉnh để kết nối AI với các data source riêng biệt.

## 🤖 12. Tích hợp AI

Áp dụng trí tuệ nhân tạo trực tiếp vào sản phẩm để tăng cường trải nghiệm người dùng.

- \***\*gemini-api-dev\*\***: Tích hợp Google Gemini vào Backend để xây dựng Chatbot tư vấn, gợi ý sản phẩm cá nhân hóa.

## 📝 13. Quản lý Yêu cầu & Tài liệu (Requirements & Documentation)

Kỹ năng quan trọng để chuyển đổi ý tưởng kinh doanh thành đặc tả kỹ thuật chính xác.

- \***\*requirements-doc-expert\*\***: 🔥 **Master Skill** - Điều phối tất cả các kỹ năng bên dưới để Review, Đánh giá và Hoàn thiện tài liệu chuyên nghiệp.
- \***\*writing-plans\*\***: Kỹ năng viết PRD (Product Requirement Document), đặc tả kỹ thuật và lộ trình thực thi chi tiết.
- \***\*api-documenter\*\***: Chuyên gia đặc tả API chuyên nghiệp với OpenAPI 3.1, xây dựng developer portals và hướng dẫn tích hợp.
- \***\*wiki-architect\*\***: Thiết kế cấu trúc Wiki, tạo hướng dẫn Onboarding và bản đồ hóa kiến trúc mã nguồn.
- \***\*docs-architect\*\***: Tư duy kiến trúc sư tài liệu, tổ chức thông tin khoa học và dễ tra cứu lâu dài.
- \***\*openapi-spec-generation\*\***: Tối ưu hóa file đặc tả OpenAPI giúp đồng bộ hóa giữa thiết kế và thực thi.
- \***\*api-documentation-generator\*\***: Tự động hóa việc tạo tài liệu Swagger/OpenAPI từ code NestJS.
- \***\*code-documentation-doc-generate\*\***: Sử dụng JSDoc và các công cụ tự động chiết xuất tài liệu từ comment trong mã nguồn.

## 📦 14. Hệ thống Background & Queue

Xử lý các tác vụ nặng một cách bất đồng bộ để giữ API luôn phản hồi nhanh.

- \***\*bullmq-specialist\*\***: Chuyên gia xử lý hàng đợi (Redis-backed queue). Quản lý job, retry và xử lý tác vụ nền (gửi mail, xử lý ảnh).

## 🛠️ 15. Bảo trì & Nâng cấp

Duy trì sự ổn định và hiện đại cho hệ thống thông qua kiểm soát dependencies.

- \***\*dependency-management-deps-audit\*\***: Quy trình audit và cập nhật thư viện hệ thống chuyên nghiệp, tránh các lỗ hổng bảo mật và code lỗi thời.

## 📊 16. Phân tích Nghiệp vụ & Sản phẩm (Business Analysis)

Hiểu sâu về sản phẩm và yêu cầu kinh doanh để xây dựng giải pháp kỹ thuật sát thực tế.

- \***\*business-analyst\*\***: Kỹ năng khơi gợi yêu cầu, xác định KPI và chuyển đổi nhu cầu kinh doanh thành giải pháp kỹ thuật.
- \***\*product-manager\*\***: Tư duy sản phẩm, quản lý yêu cầu ưu tiên (Backlog) và định hướng lộ trình phát triển.
- \***\*product-manager-toolkit\*\***: Công cụ hỗ trợ viết PRD, phân tích phỏng vấn khách hàng và ưu tiên tính năng theo RICE.
- \***\*competitive-landscape\*\***: Nghiên cứu đối thủ để làm rõ các yêu cầu tính năng cạnh tranh cho Ecommerce.
