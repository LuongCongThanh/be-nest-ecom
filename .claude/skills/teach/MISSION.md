# Mission: Back-end Development (NestJS)

## Why

Bạn là Front-end Developer muốn trở thành Full-stack Developer để có thể tự xây dựng sản phẩm hoàn chỉnh từ đầu đến cuối, tăng giá trị bản thân và mở rộng khả năng đóng góp trong team. Codebase học tập thực tế là `be-nest-ecom` — một back-end thương mại điện tử xây bằng NestJS.

## Success looks like

- Tự mình thiết kế và implement một REST API hoàn chỉnh với NestJS (module, controller, service, repository)
- Hiểu và viết được database schema với Prisma ORM, bao gồm quan hệ giữa các bảng
- Implement Authentication & Authorization (JWT, Refresh Token, RBAC) không cần nhìn tài liệu
- Viết unit test và e2e test cho các feature back-end
- Có thể đọc, debug, và review code back-end của người khác trong team

## Constraints

- Hơn 10 giờ/tuần — học cường độ cao
- Học gắn với project thực tế `be-nest-ecom`, không học lý thuyết thuần túy
- Stack cụ thể: NestJS + TypeScript + Prisma + PostgreSQL

## Out of scope

- Các back-end framework khác (Express thuần, Fastify, Django, Spring...)
- DevOps / CI-CD / Kubernetes (học sau khi nắm vững application layer)
- Microservices architecture (học sau khi thành thạo monolith trước)
