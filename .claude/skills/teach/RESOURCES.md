# Back-end (NestJS) Resources

## Knowledge

- [NestJS Official Docs](https://docs.nestjs.com)
  Tài liệu chính thức, luôn up-to-date. Dùng cho: mọi concept NestJS — modules, providers, decorators, guards, pipes, interceptors.

- [Prisma Docs](https://www.prisma.io/docs)
  Tài liệu ORM chính thức. Dùng cho: schema design, migrations, queries, relations.

- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)
  Nền tảng TypeScript. Dùng cho: generics, decorators, type system — bất kỳ lúc nào TypeScript syntax gây khó hiểu.

- [REST API Design Best Practices — Microsoft](https://learn.microsoft.com/en-us/azure/architecture/best-practices/api-design)
  Hướng dẫn thiết kế REST API chuẩn. Dùng cho: naming conventions, HTTP methods, status codes, versioning.

- [JWT.io Introduction](https://jwt.io/introduction)
  Giải thích cơ chế JWT rõ ràng. Dùng cho: hiểu sâu hơn về token structure, claims, signature.

## Wisdom (Communities)

- [r/node](https://reddit.com/r/node) — Cộng đồng Node.js/NestJS. Signal tốt, ít spam.
- [NestJS Discord](https://discord.gg/nestjsofficial) — Kênh chính thức của NestJS, core team active ở đây.
- [Stack Overflow — tag nestjs](https://stackoverflow.com/questions/tagged/nestjs) — Tìm lỗi cụ thể nhanh nhất.
