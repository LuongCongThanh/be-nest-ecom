# Mission: Backend Engineering — NestJS, Prisma & System Design

## Why

Thanh đang xây dựng một backend e-commerce thực tế với NestJS + Prisma tại SmartDev.
Mục tiêu là hiểu sâu các pattern, kiến trúc và lý do đứng sau mỗi quyết định kỹ thuật —
không chỉ để hoàn thành dự án, mà để trở thành senior developer tự tin phỏng vấn và thiết kế hệ thống.

## Success looks like

- Giải thích được "tại sao" đằng sau mỗi pattern NestJS (Module, DI, Guard, Pipe, Interceptor…)
- Thiết kế và implement Prisma schema phức tạp với relations, migrations, query optimization
- Trả lời tự tin các câu hỏi system design trong phỏng vấn senior/lead level
- Code be-nest-ecom với chất lượng production: clean architecture, error handling, testing
- Nhận ra trade-off giữa các lựa chọn kỹ thuật thay vì chỉ làm theo mẫu

## Constraints

- Học song song với công việc thực tế trên dự án be-nest-ecom
- Ưu tiên kiến thức áp dụng ngay được vào dự án hiện tại
- Phản hồi bằng tiếng Việt; code và thuật ngữ kỹ thuật giữ tiếng Anh

## Out of scope

- Frontend / React (dự án này là pure backend)
- DevOps / Kubernetes (chưa cần ở phase hiện tại)
- Microservices architecture (đang làm monolith trước)
