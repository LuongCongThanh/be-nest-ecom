# Backend Engineering Resources

## Knowledge

### NestJS

- [NestJS Official Docs](https://docs.nestjs.com)
  Nguồn chính thức, đầy đủ nhất. Dùng cho: bất kỳ câu hỏi nào về API, decorators, lifecycle.

- [NestJS Fundamentals Course — official YouTube](https://www.youtube.com/watch?v=2n3xS89TJMI)
  Video chính thức từ NestJS team. Dùng cho: hiểu Module/DI từ đầu.

- [awesome-nestjs](https://github.com/nestjs/awesome-nestjs)
  Tổng hợp patterns, boilerplates, libraries. Dùng cho: tìm giải pháp cho use-case cụ thể.

### Prisma

- [Prisma Official Docs](https://www.prisma.io/docs)
  Nguồn chính thức. Dùng cho: schema syntax, query API, migrations.

- [Prisma Data Guide](https://www.prisma.io/dataguide)
  Hướng dẫn sâu về database concepts, relations, indexing. Dùng cho: nền tảng DB.

### System Design

- [System Design Primer — GitHub](https://github.com/donnemartin/system-design-primer)
  Tổng hợp lớn nhất về system design concepts. Dùng cho: interview prep, trade-off analysis.

- [ByteByteGo Newsletter](https://blog.bytebytego.com)
  Visual system design explanations. Dùng cho: nắm nhanh các pattern phổ biến.

### TypeScript

- [TypeScript Deep Dive — Basarat](https://basarat.gitbook.io/typescript)
  Cuốn sách online miễn phí, rất thực hành. Dùng cho: advanced types, generics, patterns.

## Wisdom (Communities)

- [NestJS Discord](https://discord.gg/nestjs)
  Community chính thức. Hỏi maintainers và advanced users.

- [r/node](https://reddit.com/r/node)
  Thảo luận Node.js backend. Signal/noise ratio tốt.

- [Prisma Discord](https://discord.gg/prisma)
  Community Prisma chính thức. Hữu ích cho edge cases.
